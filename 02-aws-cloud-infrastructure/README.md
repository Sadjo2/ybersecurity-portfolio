# AWS Cloud Infrastructure

## Project Overview
This academic project involved designing and configuring AWS cloud infrastructure for a web application, with an emphasis on networking, availability and security.

## Technologies Used
- Amazon VPC and subnets
- Amazon EC2
- Amazon RDS
- Application Load Balancer
- Auto Scaling
- Security groups

## My Contribution
I worked on configuring the cloud network, deploying compute and database resources, and troubleshooting connectivity and infrastructure issues.

## Outcome
The project provided practical experience in cloud infrastructure deployment, network security and AWS architecture.
