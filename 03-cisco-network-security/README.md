# Cisco Network Security

## Project Overview
This academic project involved configuring and securing a simulated network using Cisco Packet Tracer.

## Technologies Used
- Cisco Packet Tracer
- VLANs and routing
- OSPF and BGP
- Access Control Lists (ACLs)
- NAT and PAT
- SSH

## My Contribution
I configured and tested network devices, implemented routing and access control, and troubleshot connectivity problems.

## Outcome
The project strengthened my understanding of network segmentation, secure device configuration and network troubleshooting.
